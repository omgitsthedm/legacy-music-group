## 1. Executive Summary

Legacy Music Group needs a full website overhaul that is **super clean, modern, mobile-first, visually high-end, and conversion-focused**.

The site's core purpose is simple:

* help artists understand what Legacy is immediately
* make the studio feel elite, creative, and trustworthy
* make booking extremely fast and easy

This is not just a visual refresh.
This is a new digital front door for a **Deep Ellum-based recording studio and artist development brand**.

The site should combine:

* luxury-level visual presentation
* rapid booking UX
* strong Dallas / Deep Ellum positioning
* artist development credibility
* creative community energy
* future-ready lead capture and operational structure

## 6. Design Direction

### Core style label

### Supporting design language

* modern 2026
* cinematic
* minimal
* high-contrast
* premium editorial restraint
* artist-focused
* mobile-first

### Visual traits

* near-black or carbon base
* warm off-white or bone typography
* graphite / smoke surfaces
* controlled accent moments in amber, brass, burnished gold, muted rust, or carefully chosen lighting-inspired color pops

* bright gradient soup
* corporate dashboards
* busy template layouts
* tiny type

## 7. Color Palette Direction

Use the existing Legacy dark-brand instinct, but elevate it into a more premium 2026 palette.

### Recommended palette framework

* **Base Background:** near-black / carbon / charcoal
* **Primary Text:** warm white / bone / soft ivory
* **Secondary Surfaces:** smoke / graphite / dark stone
* **Primary Accent:** brass / amber / burnished gold
* **Optional Accent Pops:** muted rust, copper, selective lighting-inspired jewel accents if used sparingly
* **UI Success / Confirmation:** restrained modern green, never neon

### Palette goals

* luxurious
* high contrast
* cinematic
* modern
* friendly enough for artists
* bold enough to convert

## 16. Booking Strategy

### Main booking goal

The booking experience should be the star of the site.

### Canonical booking logic

1. choose session type

   * with engineer
   * without engineer
2. choose optional add-ons

   * mixing & mastering
   * full package
3. if "with engineer" is selected, choose engineer
4. pick time
5. continue to contact details
6. review summary
7. accept agreement
8. pay
9. confirmation

### Booking philosophy

* fast
* clear
* calm
* premium
* mobile-first
* no multi-step chaos
* minimal cognitive load

### Core UX rule

A ready user should be able to move through the front half of the booking flow very quickly.

### Important conversion rule

There should always be a visible **Book Now** button somewhere meaningful in the interface.

### Temporary pre-launch rule

If live links are not ready yet, avoid dead buttons in public-facing states when possible.
Better temporary fallbacks:

* booking opens soon
* request priority access
* text us to book
* join the artist list
* callback request

## 31. Risks

### Main risks

* trying to be affordable and luxury in a contradictory way
* booking flow drifting into too many steps
* community content diluting conversion
* stock imagery killing authenticity
* engineer sections feeling thin without good assets
* placeholder actions going live in a confusing way

### Risk mitigation

* use premium-but-accessible language
* keep booking flow ruthless and short
* let community content support, not overwhelm
* use placeholders intentionally
* push asset collection early
